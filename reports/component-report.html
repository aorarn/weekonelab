Conventions

กติกาเมื่อเพิ่ม component ใหม่

  1. รัน npx shadcn@latest add <name> แล้วย้ายไฟล์ไปไว้ในโฟลเดอร์ ui/<Name>/
  2. <Name>.tsx มีแค่ markup กับ props ที่กำหนด type ไว้ ห้ามใส่ Tailwind class และให้ map prop ไปเป็น class ใน module เช่น styles[`size-${size}`]
  3. <Name>.module.css ขึ้นต้นด้วย @reference ไปที่ globals.css และเขียนทุก rule ไว้ใน @layer components
  4. ใส่ data-slot ให้ทุก element ใส่ data-variant / data-size ตามที่มี แล้ว merge className ไว้ท้ายสุดด้วย cn หรือ mergeClassName
  5. index.ts export ส่วนที่ใช้ภายนอก และ import จากโฟลเดอร์เสมอ เช่น @/components/ui/Card
